# 🚀 AI Trading Platform

## 🧠 Overview

AI-powered trading platform with real-time data, prediction engine, and portfolio management.

## 🏗️ Architecture

- Microservices: Backend, ML service
- Message broker: Redis
- Database: PostgreSQL
- Frontend: React

## ⚙️ Tech Stack

- Django + DRF
- React / Next.js
- FastAPI (ML)
- Docker + Nginx

## 🚀 Run locally

make run
