5. AUTHENTICATION PIPELINE (CRITICAL — FIXED)
================================================================================

BACKEND JWT FLOW (FIXED 2026-04-14):
1. User submits username + password
2. POST /api/token/ → CustomTokenObtainPairView (config/serializers.py)
3. CustomTokenObtainPairSerializer.get_token() adds to payload:
   - username
   - is_staff
   - is_superuser
4. Returns { access, refresh }

Token payload AFTER FIX:
{
  "token_type": "access",
  "exp": ...,
  "iat": ...,
  "jti": ...,
  "user_id": 1,
  "username": "admin",        ← ADDED
  "is_staff": true,          ← ADDED (was missing before!)
  "is_superuser": true       ← ADDED (was missing before!)
}

FRONTEND LOGIN FLOW:
1. authApi.login(username, password) → POST /api/token/
2. Frontend decodes JWT payload (NO backend call needed):
   const payload = data.access.split(".")[1]
   const decoded = JSON.parse(atob(payload.replace(/-/g, "+").replace(/_/g, "/")))
   const isAdmin = !!decoded.is_staff || !!decoded.is_superuser
3. login(token, { is_staff: isAdmin, username }) stores:
   - localStorage.access_token = token
   - localStorage.is_staff = "true" | "false"
   - localStorage.username = username
4. Redirect:
   isAdmin=true  → /admin/dashboard
   isAdmin=false → /app/dashboard

Logout: clears localStorage, redirects to /login

ROOT CAUSE FIX (2026-04-14 Late Session):
- Default SimpleJWT TokenObtainPairView only included: token_type, exp, iat, jti, user_id
- is_staff and is_superuser were NOT in the JWT payload
- Frontend decoded undefined → every user (including superadmin) → isAdmin=false
- Admin users were redirected to /app/dashboard instead of /admin/dashboard
- AdminRoute always redirected admin users to /app/dashboard
FIX: Created config/serializers.py with CustomTokenObtainPairSerializer
that overrides get_token() to add is_staff and is_superuser to the token.

9. KEY SERVICE FLOWS
================================================================================

A) ML PREDICTION + AUTO-TRADE FLOW:
User → GET /api/v1/predict/{TICKER}/
  → PredictionProxyView (permission=AllowAny ⚠️)
    → PredictionService.get_prediction()
      → GET http://localhost:8001/api/v1/predict/{TICKER} (ML Service)
      → Prediction.objects.create() (saved for audit)
    ← { ticker, signal, confidence, price, valid, latency_ms }
    → _maybe_auto_trade(request, prediction, result):
        IF settings.auto_trade == True
        AND signal != "HOLD"
        AND confidence >= settings.min_confidence
        AND BotConfig.is_active == True
        AND BotConfig.paper_trading == False
        THEN:
          TradeService.execute_trade(user, ticker, signal, qty)
          → Trade.objects.create()
          result["auto_executed"] = True
          result["trade_id"] = trade.id
        ELSE:
          result["auto_trade_skipped"] = "<reason>"
  ← Response with { ticker, signal, confidence, price, auto_executed,
                    trade_id, auto_trade_skipped }

B) PORTFOLIO AGGREGATION:
User → GET /api/v1/portfolio/
  → PortfolioService.get_user_portfolio(user)
    → Trade.objects.filter(user=user)
    → Groups by symbol, calculates avg_entry, unrealized_pnl
    → Returns: { balance, pnl, positions[], history[] }
  ← { balance, pnl, positions, history }

C) MANUAL TRADE EXECUTION:
User → POST /api/v1/trade/ { ticker, action, quantity }
  → TradeService.execute_trade(user, ticker, action, quantity)
    → PredictionService.get_prediction(ticker) (current price)
    → Validates balance, max_trade_amount
    → Trade.objects.create()
  ← Trade object returned

D) MARKET PRICES FLOW:
User → GET /api/v1/market/prices/
  → MarketPricesView (permission=AllowAny)
    → Loops 8 symbols → PredictionService.get_prediction()
    → If ML down: returns STATIC FALLBACK MOCK DATA
  ← Array of { symbol, price, change, change_pct, high, low, volume }

10. AUTHENTICATION & AUTHORIZATION
================================================================================
- JWT via SimpleJWT (rest_framework_simplejwt)
- Token stored in localStorage on frontend (access_token)
- Role (is_staff/is_superuser) decoded client-side from JWT payload
- Stored in localStorage as string: "true" | "false"
- Every API call includes: Authorization: Bearer <token>
- Admin users (is_superuser or is_staff): see ALL trades
- Regular users: see only their own trades (filtered by user FK)

JWT CUSTOM SERIALIZER (config/serializers.py):
  class CustomTokenObtainPairSerializer(TokenObtainPairSerializer):
      def get_token(self, user):
          token = super().get_token(user)
          token["username"] = user.username
          token["is_staff"] = user.is_staff
          token["is_superuser"] = user.is_superuser
          return token

  class CustomTokenObtainPairView(TokenObtainPairView):
      serializer_class = CustomTokenObtainPairSerializer

  Registered in config/urls.py as the /api/token/ endpoint.

ROLE DETECTION (client-side):
  const payload = data.access.split(".")[1]
  const decoded = JSON.parse(atob(payload.replace(/-/g, "+").replace(/_/g, "/")))
  const isAdmin = !!decoded.is_staff || !!decoded.is_superuser

14. AUTO-TRADE SYSTEM — IMPLEMENTED (Session 2026-04-14)
================================================================================

Backend: PredictionProxyView._maybe_auto_trade()
  Checks (in order):
    1. SystemSettings.auto_trade == True
    2. signal != "HOLD"
    3. confidence >= SystemSettings.min_confidence (default 0.75)
    4. BotConfig.is_active == True for user
    5. BotConfig.paper_trading == False for user
  If all pass:
    quantity = BotConfig.max_trade_amount / prediction["price"]
    trade = TradeService.execute_trade(user, ticker, signal, qty)
    result["auto_executed"] = True
    result["trade_id"] = trade.id
  If any fail:
    result["auto_trade_skipped"] = "<reason>"

Response fields added:
  auto_executed: boolean
  trade_id: number (if executed)
  auto_trade_skipped: string | null (reason if skipped)
  auto_trade_error: string (if exception)

Frontend: DashboardPage.js (features/dashboard/)
  After prediction response:
    auto_executed=true  → Green banner "Trade Executed Automatically"
    auto_trade_skipped → Yellow banner + reason + "Execute [SIGNAL] Trade Manually" button
    auto_trade_error   → Red banner with error message

Controlling auto-trade:
  SystemSettings.auto_trade = True/False (admin panel /admin/settings)
  SystemSettings.min_confidence = 0.0–1.0
  BotConfig.is_active = True/False (per user)
  BotConfig.paper_trading = True/False (per user)
