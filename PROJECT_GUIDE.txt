7. KEY SERVICE FLOWS
================================================================================

A) ML PREDICTION FLOW:
User → GET /api/v1/predict/{TICKER}/
  → PredictionProxyView (Django)
    → PredictionService.get_prediction()
      → GET http://localhost:8001/api/v1/predict/{TICKER} (ML Service)
        → ML Service: fetches yfinance data → runs LSTM → returns JSON
      ← normalize_ml_response() (adapter layer)
      → Prediction.objects.create() (saved to DB for audit)
    ← { ticker, signal, confidence, price, valid, latency_ms }
  ← Response to frontend
User sees: "BUY" or "SELL" or "HOLD" signal with confidence bar

B) PORTFOLIO AGGREGATION:
User → GET /api/v1/portfolio/
  → PortfolioService.get_user_portfolio(user)
    → Trade.objects.filter(user=user)  (user's own trades only)
    → Groups by symbol
    → Calculates: quantity, avg_entry, current_price (via ML), unrealized_pnl
    → Returns: { balance, pnl, positions[], history[] }
  ← { balance, pnl, positions, history }
User sees: Holdings table + pie chart + balance

C) TRADE EXECUTION (defined but not called from UI):
User → POST /api/v1/trade/ { ticker, action, quantity }
  → TradeService.execute_trade(user, ticker, action, quantity)
    → PredictionService.get_prediction(ticker) (current price)
    → Validates: balance, max_trade_amount, position qty
    → Calculates FIFO PnL for SELL
    → Trade.objects.create() (saved to DB)
  ← Trade object returned
NOTE: This endpoint EXISTS in the backend but has NO UI trigger in the
frontend. The "Execute Trade" button is not implemented.

D) MARKET PRICES FLOW:
User → GET /api/v1/market/prices/
  → MarketPricesView
    → Loops 8 symbols (BTC, ETH, TSLA, AAPL, NVDA, MSFT, GOOGL, AMZN)
    → Calls PredictionService.get_prediction() for each
    → If ML service is DOWN: returns STATIC FALLBACK MOCK DATA
  ← Array of { symbol, price, change, change_pct, high, low, volume }
User sees: Price cards with up/down indicators

8. AUTHENTICATION & AUTHORIZATION
================================================================================
- JWT via SimpleJWT (rest_framework_simplejwt)
- Token stored in localStorage on frontend (access + refresh)
- Every API call includes: Authorization: Bearer <token>
- Admin users (is_superuser or is_staff): see ALL trades
- Regular users: see only their own trades (filtered by user FK)

JWT ENDPOINTS:
  POST /api/token/        → { access, refresh }
  POST /api/token/refresh/ → { access }

11. CURRENT LIMITATIONS (NOT IMPLEMENTED)
================================================================================
⚠️ MANUAL TRADE EXECUTION: TradeService.execute_trade() exists in backend
   but there is NO "Execute Trade" button in the frontend UI. User must use
   Postman or curl to trigger a trade.

⚠️ AUTO-TRADE SYSTEM: SystemSettings.auto_trade flag exists but has no
   effect. No Celery task reads this flag to auto-execute trades.

⚠️ LOGS ARE MOCKED: CeleryLogsView and AuditLogsView return hardcoded
   static arrays, not real Celery task results or Django LogEntry records.

⚠️ ML MODELS PAGE IS MOCKED: Returns hardcoded model health data.
   Does not scan actual .keras files in ml_service/models/.

⚠️ MARKET PRICE FALLBACK IS STATIC: When ML service is down, market prices
   show hardcoded values (BTC=$70000) regardless of real market.

⚠️ PORTFOLIO CACHING: PortfolioService calls PredictionService for every
   ticker on every page load. No Redis caching implemented.

⚠️ PREDICTION DOES NOT AUTO-TRADE: A prediction signal (BUY/SELL) is
   displayed but does not trigger a trade. Operator must manually act.

12. HOW TO RUN (LOCAL)

A) PREREQUISITES:
   - Python 3.10+
   - Node.js 18+
   - PostgreSQL 15 running on port 5432
   - Redis running on port 6379 (for Celery)

B) BACKEND:
   cd backend
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   python manage.py makemigrations administration
   python manage.py migrate
   python manage.py runserver 0.0.0.0:8000

C) ML SERVICE:
   cd ml_service
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   uvicorn main:app --host 0.0.0.0 --port 8001

D) FRONTEND:
   cd frontend
   npm install
   npm start
